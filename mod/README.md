Ascendant Tiers is a Desynced mod that adds a Tier 2 progression layer for modular buildings, components, and robot units.

The mod expands on vanilla progression by introducing upgraded T2 variants, a dedicated research path, and a set of custom materials used to craft the new content. The goal is to keep the overall feel close to the base game while giving more room to scale into stronger modular setups.

Current content includes:

* Tier 2 buildings
* Tier 2 components
* Tier 2 robot units
* custom T2 technologies
* custom upgrade materials
